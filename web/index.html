A rescue stick with an agent inside.

NixOS live system. opencode, Claude Code and Codex ready at the console. Your API key goes into the image while it downloads, in your browser, so the stick works the moment it boots.

Download

Wi-Fi, SSH, keyboard (optional)

The image is downloading from GitHub and your configuration was saved as rescue-config.json. GitHub does not let the browser rewrite the image, so run one of these in the folder with both files:

Both write the configuration into the image in place. Then write it to a stick as usual.

The key never leaves your browser. The page streams the image from the download server, replaces one 16 KiB block in place and hands the result to your disk. The original image's checksum is verified while it streams.

How it works

  1. Write the ISO to a USB stick with dd, Etcher or Ventoy. Any method works, the key sits in a normal file inside the image.
  2. Boot. You land in a console with a menu. If you entered Wi-Fi, the stick is already online.
  3. rescue-mount finds the installed system, unlocks it and mounts it read-only. Then talk to opencode, Claude Code or Codex about what is wrong.
  4. No key? Press C-Space k and enter one from your phone via QR code, or sign in to Claude or Codex with your subscription the same way.

Read-only first, destructive commands only after an explicit yes, backups before edits: the agents carry these rules as their instructions.

Build it yourself

The whole system is one Nix flake. Build the image, patch a slot, or bake your configuration in at build time.

nix build github:2342-ai/agentic-rescue#iso
nix run github:2342-ai/agentic-rescue#patch -- result/iso/*.iso \
  --provider groq --key gsk_… --wifi "Home" "secret" -o my-rescue.iso
