What happens at boot

  1. Console, not desktop. kmscon with a real font and truecolor, tmux underneath, a menu on top. A second boot entry without modesetting for difficult GPUs.
  2. Your settings apply. Keys become environment variables and agent configuration, Wi-Fi connects, your SSH key is authorized.
  3. Find the patient. rescue-mount unlocks LUKS, assembles LVM and RAID, imports ZFS pools and mounts the installed system read-only at /mnt.
  4. Talk it through. opencode, claude or codex. The agent reads logs, explains, proposes. Repairs run in a chroot, after your yes.

No key in the image? Press C-Space k at the console and type it on your phone via QR code. Claude and Codex subscribers sign in the same way.

Questions

What is Agentic Rescue?

A free, bootable Linux rescue system for a USB stick. It is a NixOS live ISO with the AI coding agents opencode, Claude Code and Codex installed, next to the usual rescue tools: ddrescue, testdisk, smartctl, cryptsetup, ZFS, Btrfs, LVM and mdadm.

How is it different from SystemRescue (SystemRescueCd)?

SystemRescue is the classic Arch-based rescue toolkit with GParted and an optional graphical desktop. Agentic Rescue is NixOS-based, console-only, and adds three AI agents that read the logs of the broken system, explain what they find and propose repairs. If you want a graphical partition editor, use SystemRescue. If you want help finding the cause, use Agentic Rescue.

Is it free? Do I need an AI subscription?

The ISO is free and MIT licensed. The agents need a model: bring an API key (Groq, Google AI Studio and OpenRouter have free tiers), use one 2342.ai key for all three agents, or sign in with an existing Claude or ChatGPT subscription at the console.

Which systems can it repair?

Linux installs of any distribution: NixOS, Arch and its derivatives, Debian, Ubuntu and Fedora, encrypted with LUKS or not, on ext4, Btrfs, XFS or ZFS. For Windows it can mount NTFS, copy files off the disk and reset local passwords with chntpw, but it does not run Windows repair tools.

Does it work without internet?

The published image needs a network connection for the agents. Ethernet works automatically, Wi-Fi is set up with impala or written into the image on this page. An offline variant with a local language model can be built from source with nix build .#iso-offline.

Does it boot with Secure Boot enabled?

Not yet. The image is not signed for Secure Boot. Switch Secure Boot off in the firmware settings to boot the stick, and switch it back on when you are done.

Is my API key safe?

The key never leaves your browser: the page writes it into your own copy of the image. On the stick it is stored in plain text, so whoever holds the stick holds the key. Create a key just for the stick and give it a budget.

How do I put the ISO on a USB stick?

With any tool that writes disk images: dd on Linux and macOS, balenaEtcher, Rufus in DD image mode, or Ventoy. The stick needs at least 4 GB.

Build it yourself

One Nix flake. Build the image, patch the slot, or bake your configuration in at build time.

nix build github:2342-ai/agentic-rescue#iso
nix run github:2342-ai/agentic-rescue#patch -- result/iso/*.iso \
  --provider groq --key gsk_… --wifi "Home" "secret" -o my-rescue.iso
